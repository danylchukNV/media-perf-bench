- [x] Перевірити на Windows увесь ланцюжок. Працює. Знайдено й виправлено: для фото з EXIF-поворотом (25 з 65) у маніфест ішли розміри до повороту (`autoOrient` є лише в sharp ≥ 0.34).

## Відомі особливості

- Емуляція мережі DevTools не моделює втрати пакетів; сервер працює через HTTP/1.1.
- `persist` (збереження оцінок між візитами) у бенчмарку не впливає, бо кожен прогін починається з чистого профілю.
- Під час програмного стрибка прокручування (`scrollTo`) швидкість різко зростає і метод завантажує багато наперед. У сценарії раннера прокручування плавне, тож це його не стосується.
- Google Docs із тезами Claude Code напряму не редагує (немає конектора). Правки в тези вносити вручну або через claude.ai з конектором Google Drive.
